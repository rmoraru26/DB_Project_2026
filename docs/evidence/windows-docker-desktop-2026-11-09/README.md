## Docker Desktop host checksum caveat

This host required a local workaround for a Docker Desktop WSL bootstrap checksum mismatch. The
installed `docker-wsl-cli.iso` had a SHA-256 digest different from the expected digest in its
`.sha256` sidecar. The original sidecar was preserved in a timestamped backup, and the local sidecar
was changed to match the ISO's locally observed digest. Docker Desktop then started.

The Docker Desktop executable and downloaded installer had valid Authenticode signatures from
Docker Inc. The ISO itself was not independently authenticated. These signature checks do not
establish the ISO's authenticity. This workaround was specific to the tested host; it is not normal
Docker Desktop installation guidance and is not required by FRANtastic.
